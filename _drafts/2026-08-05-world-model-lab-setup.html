从零搭建世界模型实验环境：MuJoCo + DreamerV3 实战指南

2026年8月5日 · 阅读约15分钟 · 实战教程, MuJoCo, DreamerV3, 世界模型

前面写了好几篇世界模型的理论文章——从RSSM的数学原理到Sim-to-Real迁移，到VLA和世界模型的对比。有读者问：道理我都懂了，怎么动手跑起来？

今天这篇就是回答这个问题的。我会手把手带你搭建一个完整的世界模型实验环境，从安装到训练到可视化，一步步走通。跑通之后，你就可以在这个基础上做自己的实验了。

我们选用的工具链是：MuJoCo（物理仿真）+ DreamerV3（世界模型）+ TensorBoard（可视化）。如果你需要更高保真度的渲染，后面可以替换为Isaac Sim，但入门阶段MuJoCo足够了。

工具选型：为什么是这三个

MuJoCo：目前机器人仿真领域最主流的引擎之一。物理精度高、API简洁、速度快。2021年被DeepMind收购后开源免费，现在是机器人学习研究的事实标准。大部分世界模型论文都用MuJoCo做实验。

DreamerV3：Danijar Hafner等人开发的世界模型算法，是Dreamer系列的第三代。它用RSSM（循环状态空间模型）学习环境动态，在想象空间中训练Actor-Critic策略。代码开源，文档清晰，是学习世界模型最好的起点。

TensorBoard：TensorFlow自带的可视化工具，DreamerV3原生支持。可以实时查看训练曲线、想象空间的可视化、Agent的行为录像等。

第一步：环境准备

先确认你的系统环境：

  • 操作系统：Linux（推荐Ubuntu 20.04/22.04）或 macOS。Windows用户建议用WSL2
  • Python：3.10 或 3.11（DreamerV3对Python版本有要求）
  • GPU：可选但强烈推荐。有NVIDIA GPU可以显著加速训练
  • 内存：建议16GB以上

创建一个新的conda环境：

conda create -n worldmodel python=3.11
conda activate worldmodel

第二步：安装MuJoCo

MuJoCo现在可以通过pip直接安装，比以前方便很多：

pip install mujoco

验证安装是否成功：

python -c "import mujoco; print(mujoco.__version__)"

如果输出版本号，说明安装成功。

如果你想要可视化渲染（看到机器人的3D画面），还需要安装渲染后端。Linux上推荐用EGL或OSMesa：

# Linux (有GPU)
pip install mujoco[extras]

# Linux (无GPU，headless渲染)
sudo apt-get install libosmesa6-dev
pip install mujoco[extras]

第三步：安装DreamerV3

DreamerV3的官方代码在GitHub上。直接克隆并安装依赖：

git clone https://github.com/danijar/dreamerv3.git
cd dreamerv3
pip install -r requirements.txt
pip install -e .

如果你要用MuJoCo环境做实验，还需要安装对应的环境包：

# MuJoCo控制任务（经典RL benchmark）
pip install dm-control

# DeepMind控制套件（包含大量预定义任务）
pip install dm-control-suite

验证DreamerV3是否可以正常导入：

python -c "import dreamerv3; print('DreamerV3 ready!')"

第四步：跑第一个实验

环境都装好了，现在来训练一个世界模型。我们选一个简单的MuJoCo任务：Walker Walk——让一个双足机器人学会走路。

运行训练命令：

python dreamerv3.py \
  --logdir ~/logdir/wm_walker_walk \
  --configs defaults mujoco_control \
  --task dm_control_walker_walk \
  --steps 1e6

参数说明：

  • --logdir：日志和模型保存路径
  • --configs：预设配置，defaults是基础配置，mujoco_control是MuJoCo任务专用配置
  • --task：具体任务名，walker_walk是双足行走任务
  • --steps 1e6：训练100万步（大约需要几十分钟到几小时，取决于硬件）

如果你只是想快速验证流程是否跑通，可以先用少量步数：

python dreamerv3.py \
  --logdir ~/logdir/wm_test \
  --configs defaults mujoco_control \
  --task dm_control_walker_walk \
  --steps 1e4

1万步大概几分钟就能跑完，足以验证整个流程。

第五步：可视化训练过程

训练跑起来之后，打开另一个终端，启动TensorBoard查看训练曲线：

tensorboard --logdir ~/logdir/wm_walker_walk --port 6006

浏览器打开 http://localhost:6006，你会看到几类重要的指标：

1. 训练奖励（train/return）：这是最核心的指标，代表Agent在真实环境中的累计奖励。随着训练进行，这个值应该逐渐上升。

2. 想象奖励（eval/return）：Agent在想象空间中评估的策略表现。如果想象奖励和真实奖励差距很大，说明世界模型的精度可能不够。

3. 世界模型重建误差（losses/recon）：RSSM对观测的重建误差。这个值下降说明世界模型正在学习环境动态。

4. 奖励预测误差（losses/reward）：世界模型对奖励的预测准确度。

TensorBoard里还有一个很有用的功能：视频回放。在Images标签页下，你可以看到Agent在真实环境和想象空间中的行为录像。对比两者，可以直观感受世界模型的"想象"质量。

第六步：理解训练输出

训练完成后，logdir下的目录结构大概是这样的：

~/logdir/wm_walker_walk/
├── events.out.tfevents.*    # TensorBoard日志
├── configs.yaml              # 训练配置
├── variables.pkl             # 模型权重
└── metrics.json              # 指标记录

你可以用Python加载metrics.json来分析训练过程：

import json
import matplotlib.pyplot as plt

with open('~/logdir/wm_walker_walk/metrics.json') as f:
    metrics = [json.loads(line) for line in f]

steps = [m['step'] for m in metrics]
returns = [m['eval/return'] for m in metrics]

plt.plot(steps, returns)
plt.xlabel('Training Steps')
plt.ylabel('Eval Return')
plt.title('DreamerV3 on Walker Walk')
plt.savefig('training_curve.png')
plt.show()

常见问题排查

问题1：MuJoCo渲染报错 "GLFW error"

这通常是因为没有正确配置渲染后端。如果你在远程服务器或无显示器的机器上，设置环境变量使用离屏渲染：

export MUJOCO_GL=egl   # 有GPU
# 或
export MUJOCO_GL=osmesa  # 无GPU

问题2：DreamerV3训练很慢

几个可能的原因：没有GPU（纯CPU训练会慢10倍以上）、batch size太大（可以减小）、环境并行数不够。如果有GPU，确认PyTorch/JAX正确识别了CUDA。

问题3：训练奖励不上升

可能是学习率不合适、任务太难、或者训练步数不够。建议先换一个简单的任务（比如reach任务）验证流程，再切换到难任务。DreamerV3的默认超参数在大部分MuJoCo任务上是调好的，一般不需要修改。

问题4：内存溢出（OOM）

DreamerV3需要存储replay buffer，如果内存不够可以减小buffer size。在configs里修改 buffer_size=1e5（默认更大）。

下一步：从MuJoCo到Isaac Sim

MuJoCo适合快速验证算法，但渲染真实度有限。如果你需要更逼真的视觉输入（比如训练一个从摄像头画面识别物体的机器人），可以升级到NVIDIA Isaac Sim。

Isaac Sim基于Omniverse平台，提供物理精确的仿真和高保真渲染。它和MuJoCo的API不同，但DreamerV3的训练流程是一样的——只需要写一个环境包装器，把Isaac Sim的观测和动作接口适配成DreamerV3期望的格式。

这个进阶话题我后续会单独写一篇。目前阶段，先把MuJoCo + DreamerV3跑通，理解世界模型的训练流程，才是最重要的。

总结

今天我们搭建了一个完整的世界模型实验环境：MuJoCo负责物理仿真，DreamerV3负责世界模型训练，TensorBoard负责可视化。整个流程从安装到跑通第一个实验，大概需要半小时到一小时（取决于网速）。

跑通之后，你可以尝试：

  • 换不同的MuJoCo任务（cheetah run、hopper stand、humanoid walk等）
  • 调整超参数，观察想象空间质量的变化
  • 对比DreamerV3和传统RL（比如PPO）的样本效率
  • 在世界模型中加入语言条件，探索语言接地的可能性

实践出真知。跑过一遍实验，你对世界模型的理解会比读十篇论文更深。
