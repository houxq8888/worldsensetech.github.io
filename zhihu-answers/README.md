# 知乎运营策略

## 回答风格指南

1. **开头直接给结论**，不要铺垫太长。知乎读者没耐心看长前言。
2. **用"做XX方向大半年"的身份切入**，建立专业可信度。
3. **分点论述但不超过5点**，每点2-3句话说清楚。
4. **末尾附博客链接**，格式：「更多分析见我的博客 worldsensetech.com」
5. **字数控制在600-1000字**，太长没人看完。
6. **避免纯学术腔**，用工程师视角说人话。

## 话题优先级（从高到低）

1. 世界模型技术进展（核心领域）
2. 具身智能行业分析（流量大）
3. 强化学习入门/学习路径（长尾搜索）
4. Sim-to-Real技术细节（专业深度）
5. 职业发展建议（共鸣度高）
6. 哲学/思辨类话题（偶尔蹭热度）

## 日常节奏

- **每天回答1个知乎问题**，保持活跃度
- **每周写1篇博客新文章**，作为知乎回答的素材库
- **每月回顾一次知乎数据**，调整内容方向
- **公众号文章和知乎回答错开**，避免同一天发同一内容

## 数据驱动调整

- 回答24小时内阅读量 > 50 → 话题受欢迎，后续多写同方向
- 回答被折叠 → 检查是否太短或太水，重写后删除旧回答重新发布
- 收到新邀请且话题很对口 → 调整排期，优先回答专业匹配度最高的
- 当天有重大行业新闻 → 优先回答与新闻相关的问题，蹭搜索热度
- 每周回顾一次数据 → 淘汰低效话题类型，集中在高流量方向
